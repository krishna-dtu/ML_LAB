# Machine Learning Lab (CO303)

This repository contains Machine Learning laboratory experiments completed as part of the CO303 Machine Learning Lab course. Each experiment includes implementation, observations, results, and conclusions using Python and Google Colab.

---

## Lab 01 - Build and Test Your First ML Classifier

### Objective
To build and evaluate a K-Nearest Neighbors (KNN) classifier using the Iris dataset.

### Topics Covered
- Iris Dataset
- Data Exploration
- Data Visualization
- KNN Classification
- Train-Test Split
- Model Evaluation
- Feature Scaling
- Class Probabilities

### Tools & Libraries
- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

---

## Lab 02 - Problem Formulation, Dataset Inspection and Baseline Modelling

### Objective
To inspect and assess the quality of a dataset, formulate a machine learning problem, establish baseline models, and compare them with a Logistic Regression classifier using the Titanic dataset.

### Topics Covered
- Problem Formulation
- Dataset Inspection
- Dataset Health Checks
- Missing Value Analysis
- Duplicate Record Detection
- Feature and Target Separation
- Train-Test Split
- DummyClassifier Baselines
- Logistic Regression
- Model Comparison

### Tools & Libraries
- Python
- Google Colab
- NumPy
- Pandas
- Scikit-learn

---

## Datasets Used

### Iris Dataset
- Source: Scikit-learn Built-in Dataset
- Type: Multi-class Classification

### Titanic Dataset
- Source: Kaggle Titanic Dataset
- Type: Binary Classification
